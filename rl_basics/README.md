# 강화학습 기본 예제

쉬운 것부터 4개. 순서대로 하나씩 실행하고, 파일을 열어 주석을 읽는다.
각 파일 맨 위에 "상황 / 배울 것 / 실행 방법"이 있다.

VS Code에서 파일을 열고 오른쪽 위 ▶를 누르거나, 터미널에서 아래 명령을 쓴다.

| 순서 | 파일 | 무엇 | 걸리는 시간 |
| --- | --- | --- | --- |
| 1 | `ex01_gridworld_qlearning.py` | 5×5 미로에서 길 찾기. Q 표를 직접 채움 (라이브러리 없음) | 1초 |
| 2 | `ex02_cartpole_dqn.py` | 수레로 막대 세우기. Q 표 대신 신경망 (DQN) | 약 1분 20초 |
| 3 | `ex03_pendulum_sac.py` | 진자 거꾸로 세우기. 연속 행동 (SAC) | 약 1분 30초 |
| 4 | `ex04_my_env_stop_line.py` | 환경 직접 만들기. 정지선에 차 세우기, RL vs PD 제어 | 약 1분 |

```bash
.venv\Scripts\python rl_basics/ex01_gridworld_qlearning.py
.venv\Scripts\python rl_basics/ex02_cartpole_dqn.py --show
.venv\Scripts\python rl_basics/ex03_pendulum_sac.py --show
.venv\Scripts\python rl_basics/ex04_my_env_stop_line.py
```

`--show`를 붙이면 학습이 끝난 뒤 창이 떠서 직접 움직이는 모습을 볼 수 있다.

## 각 예제에서 볼 것 (이 PC에서 실제로 나온 값)

### 1. 미로 길 찾기 (Q-learning)
에피소드 1, 10, 50, 100, 500에서 칸마다 "가장 좋다고 생각하는 방향"을 화살표로 찍는다.
처음엔 `?`와 엉뚱한 화살표뿐이다가, 500번 뒤에는 구덩이(X)를 피해 8걸음 만에 목표(G)에 도착한다.

- **Q 값**: "이 칸에서 이 방향으로 가면 앞으로 받을 점수". 출발 칸의 Q가 `[5.96 6.38 5.96 6.32]`(↑↓←→)이면 ↓로 간다.
- **탐험 ε**: 처음엔 100% 무작위로 돌아다니며 정보를 모으고, 점점 아는 대로 간다.
- **벨만 방정식**: `목표 = 보상 + 0.95 × 다음 칸의 가장 큰 Q`. 목표 근처 칸의 높은 점수가 한 칸씩 뒤로 전해진다.

### 2. 막대 세우기 (DQN)
| 학습 | 평균 점수 (500 만점) |
| --- | ---: |
| 학습 전 | 12 |
| 1만 스텝 | 152 |
| 2만 스텝 | 138 |
| 4만 스텝 | 112 |
| 5만 스텝 | 500 |

점수가 **오르락내리락한다**. 강화학습은 원래 이렇게 불안정하다. 그래서 학습 중간 성능을 자주 재 보고, 가장 좋았던 모델을 저장해 두는 게 보통이다.

### 3. 진자 세우기 (SAC)
학습 전 −1296 → 6천 스텝 −170 → 1만 5천 스텝 −143. −200보다 높으면 거의 세운 것이다.
행동이 연속값(토크 −2~2)이라 DQN을 못 쓰고 SAC를 쓴다. slam-sim 경로 따라가기 RL도 같은 SAC다.
힘이 약해 한 번에 못 올리므로 **앞뒤로 흔들어 반동을 쓰는 법**을 스스로 찾는다. `--show`로 보면 보인다.

### 4. 정지선에 서기 (환경 직접 만들기)
| | 점수 | 최종 위치 | 10 cm 안 도착 |
| --- | ---: | ---: | ---: |
| PD 제어 (게인 0.5, 1.0) | −23.9 | 9.96 m | 8.5초 |
| RL (SAC, 1만 스텝) | −18.6 | 10.01 m | 4.1초 |
| PD, 마찰 0.5 (처음 보는 조건) | −27.8 | 9.88 m | 도착 못 함 |
| RL, 마찰 0.5 (처음 보는 조건) | −21.8 | 10.01 m | 5.1초 |

여기서는 RL이 더 빨리 섰다. 단, **PD 게인은 아무렇게나 정한 값이다.** 게인을 바꿔 보면 PD도 훨씬 빨라질 수 있다. 직접 해 보는 것이 이 예제의 숙제다.

- 환경은 `reset()`(처음 상태로)과 `step(행동)`(한 스텝 진행 → 다음 관측, 보상, 끝났나) 두 함수면 된다.
- 보상 식을 바꾸면 RL의 운전 습관이 바뀐다. 페달 감점 `0.01`을 0이나 0.1로 바꿔 보자.
